# Source notes

This starter project is seeded from the uploaded learning material.

## SQL
The SQL source covers the EMP/DEPT sample dataset and a progression from SELECT/WHERE through logical operators, aggregation, GROUP BY/HAVING, subqueries, joins, self joins, ranking, CTEs and window functions. The first production seed uses the cleaned concepts from the fresher guide rather than copying every typo from the original question bank.

## Excel
The Excel guide is used as the curriculum basis for SUM/AVERAGE/COUNT, conditional logic, SUMIFS/COUNTIFS, XLOOKUP/VLOOKUP, text cleaning, dates, statistics, dynamic arrays and Power Query.

## Python and Data Engineering
Python and Data Engineering starter questions extend the same learning style into core Python, Pandas, ETL, data quality, modeling and pipeline concepts. They are intentionally editable through the admin question bank.
